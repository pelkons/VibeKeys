# VibeKeys

Маленькая плавающая панель с клавишами для работы без клавиатуры (мышка + голос).
Панель не забирает фокус: кликнули в поле ввода, потом на кнопку — клавиша уходит в это поле.
Держится поверх всех окон, включая панель задач.

## Кнопки

| Иконка | Клавиша |
|---|---|
| 🎤 | Win+Alt (диктовка OpenWhispr, с автостопом — см. ниже) |
| ✓ | Ctrl+Enter (подтвердить) |
| ↵ | Enter |
| ≡ | Shift+Enter (новая строка) |
| ⌫ | Backspace |
| ↶ | Ctrl+Z (отменить) |
| Esc | Escape |
| ✂ | Win+Shift+S (скриншот области) |

Левая зона с точками: тянуть левой кнопкой — переместить, правый клик — меню «Скрыть в трей» / «Выход».
Позиция запоминается в `%APPDATA%\VibeKeys\position.txt`.

## Знаки по долгому нажатию Backspace

Если подержать кнопку ⌫ (около полсекунды), над ней всплывает столбик со знаками `.` `?` `,` `!`
(точка ближе всего к кнопке). Знак можно выбрать кликом или, не отпуская кнопку, довести мышку
до знака и отпустить. Столбик закрывается сам, если мышка ушла от него на полторы секунды.
Знаки печатаются как символы, поэтому раскладка (русская/английская) не важна.
Набор знаков — константа `BackspaceSymbols` в начале `VibeKeys.cs`, время удержания — `LongPressMs`.

## Автостоп диктовки

Кнопка микрофона нажимает Win+Alt (OpenWhispr начинает запись), подсвечивается синим и сама слушает
микрофон по умолчанию (`SilenceWatcher.cs`). Когда после речи наступает пауза 2 секунды, она снова
нажимает Win+Alt — OpenWhispr останавливается и вставляет текст. Если за 8 секунд ничего не сказано,
запись тоже останавливается. Короткие звуки (щелчок мышки, стук) паузу не прерывают — только
сплошной звук от четверти секунды. На всякий случай запись в любом случае останавливается через 5 минут. Повторный клик по подсвеченной кнопке останавливает запись вручную.
Паузы настраиваются константами `SilenceMs` и `NoSpeechMs` в начале `VibeKeys.cs`.

Если остановить OpenWhispr не через панель (например, клавишами), панель об этом не узнает и через
несколько секунд нажмёт Win+Alt сама — то есть запустит запись снова.

## Трей

Программа живёт в трее (синяя клавиша со стрелкой Enter). Левый клик по значку — показать/скрыть панель,
правый клик — меню: «Показать / скрыть панель», «Запускать вместе с Windows» (галочка) и «Выход».

Автозапуск включён по умолчанию: программа прописывает себя в
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. Если снять галочку, запись удаляется, а выбор
запоминается в `%APPDATA%\VibeKeys\autostart.txt`, чтобы при следующем запуске автозапуск не включился снова. Windows 11 прячет новые значки под стрелочкой «^»; чтобы значок был виден всегда:
Параметры → Персонализация → Панель задач → Другие значки в области уведомлений → VibeKeys.

## Файлы

- `VibeKeys.cs` — основной код программы. Список кнопок — массив `Keys_` в начале файла.
- `SilenceWatcher.cs` — прослушивание микрофона для автостопа диктовки.
- `SymbolPopup.cs` — всплывающий столбик знаков над кнопкой.
- `NoFocus.cs` — окно и кнопка, которые не забирают фокус у поля ввода.
- `build.cmd` — сборка `VibeKeys.exe` встроенным в Windows компилятором C#, ничего ставить не нужно.
- `vibekeys.ico` — иконка программы (встраивается в exe при сборке).
- `VibeKeys.exe` — готовая программа.
- `tools\` — вспомогательные скрипты PowerShell, которыми программа проверялась:
  - `test-vibekeys.ps1` — открывает Блокнот, кликает кнопки панели и печатает получившийся текст;
  - `menutest.ps1` — проверяет меню по правому клику;
  - `leveltest.cmd` (+ `LevelTest.cs`) — печатает уровень микрофона и момент, когда сработал бы автостоп; клавиш не нажимает;
  - `popuptest.ps1` — в новом Блокноте проверяет короткий клик и долгое нажатие Backspace;
  - `silencetest.ps1` — включает микрофон и без речи следит, что автостоп выключил запись;
  - `mictest.ps1` — нажимает кнопку микрофона в Блокноте и проверяет, что OpenWhispr начал запись;
  - `zorder.ps1` — проверяет, что панель остаётся над панелью задач;
  - `shot.ps1` — снимок окна панели;
  - `make-icon.ps1` — рисует `vibekeys.ico` (`make-icon.ps1 vibekeys.ico preview.png`);
  - `grid.ps1` — таблица иконок шрифта Segoe Fluent Icons с кодами, чтобы подбирать значки.

## Как поменять кнопки

1. Отредактировать `Keys_` в `VibeKeys.cs` (иконка из Segoe Fluent Icons как `\uXXXX`, подсказка, коды клавиш).
2. Закрыть программу (правый клик → «Выход»).
3. Запустить `build.cmd`, затем `VibeKeys.exe`.

Ограничение: в программы, запущенные от администратора, Windows не даёт панели нажимать клавиши.
