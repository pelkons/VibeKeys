# VibeKeys для macOS

Та же плавающая панель клавиш, что и для Windows: живёт в строке меню (значок клавиатуры), в Dock не
появляется. Панель не забирает фокус, держится поверх всех окон и Dock, на всех рабочих столах.

## Кнопки

| Значок | Клавиши |
|---|---|
| 🎤 | диктовка OpenWhispr с автостопом (сочетание выбирается в меню) |
| ✓ | Cmd+Enter (подтвердить) |
| ↵ | Enter |
| ≡ | Shift+Enter (новая строка) |
| ↶ | Cmd+Z (отменить) |
| esc | Escape |
| 📷 | Cmd+Shift+4 (скриншот области) |
| ⌫ | Backspace; подержать — столбик `.` `?` `,` `!` |

На Mac вместо Ctrl используется Command, как принято в macOS.

## Установка

1. Скачайте `VibeKeys-macos.zip` из релиза, распакуйте и перенесите `VibeKeys.app` в «Программы».
2. Первый запуск: правый клик по приложению → «Открыть» (оно не подписано сертификатом Apple).
3. Разрешите VibeKeys управлять компьютером: «Системные настройки → Конфиденциальность и безопасность →
   Универсальный доступ» — включите VibeKeys. Без этого кнопки не смогут нажимать клавиши.
   Пока разрешения нет, в меню значка есть пункт «Разрешить управление клавиатурой…».
4. При первом нажатии на микрофон macOS спросит доступ к микрофону — он нужен только для автостопа.

## Меню

- **Значок в строке меню:** показать/скрыть панель, «Масштаб» (30–200 %), «Сочетание для диктовки»
  (Control+Command — по умолчанию в OpenWhispr, Command+Option, Fn/Globe), «Запускать при входе в
  систему» (включено по умолчанию), «Выход».
- **Правый клик (или Control-клик) по ручке слева:** «Масштаб», «Скрыть панель», «Выход».
- Ручку можно тянуть, чтобы переместить панель; место запоминается.

## Сборка

Нужны Command Line Tools (`xcode-select --install`), macOS 13 или новее.

```bash
./build.sh
```

Получится `build/VibeKeys.app` (универсальная: Apple Silicon и Intel). Сборка подписывается локально,
поэтому после каждой пересборки macOS заново спросит разрешение «Универсальный доступ».

`VibeKeys --demo` показывает панель с подсвеченным микрофоном и открытым столбиком знаков — так CI
делает снимок экрана.

## Файлы

- `Sources/main.swift` — запуск, меню в строке меню, автозапуск.
- `Sources/Panel.swift` — панель, кнопки, масштаб, автостоп, долгое нажатие Backspace.
- `Sources/KeyButton.swift` — скруглённая кнопка и ручка.
- `Sources/SymbolPopup.swift` — столбик знаков.
- `Sources/Keyboard.swift` — нажатие клавиш и печать символов.
- `Sources/SilenceWatcher.swift` — прослушивание микрофона для автостопа.
- `Sources/Settings.swift` — настройки.
- `AppIcon.png` — иконка (рисуется `windows/tools/make-icon.ps1 -MacPng`).
