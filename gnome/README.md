# VibeKeys для Ubuntu (расширение GNOME Shell)

Та же плавающая панель клавиш, что и для Windows, в виде расширения для стандартного рабочего стола
Ubuntu (GNOME на Wayland). Обычная программа на Wayland не может стоять поверх окон и при этом не забирать
фокус, поэтому VibeKeys встроена в саму оболочку: панель не забирает фокус у окна, в котором вы печатаете,
а клавиши уходят через виртуальную клавиатуру по физическим кодам — раскладка не важна.

Поддерживается GNOME 45–48: Ubuntu 24.04 и новее. Ubuntu 22.04 (GNOME 42) не поддерживается.

## Кнопки

| Значок | Клавиши |
|---|---|
| 🎤 | диктовка OpenWhispr с автостопом (сочетание выбирается в меню) |
| ✓ | Ctrl+Enter (подтвердить) |
| ↵ | Enter |
| ≡ | Shift+Enter (новая строка) |
| ↶ | Ctrl+Z (отменить) |
| Esc | Escape |
| 📷 | Print Screen (скриншот, выделение области) |
| ⌫ | Backspace; подержать — столбик `.` `?` `,` `!` |

## Установка

```bash
gnome-extensions install --force vibekeys@pelkons.github.io.shell-extension.zip
```

Затем выйдите из сеанса и войдите снова (на Wayland оболочка подхватывает новые расширения только после
перезахода) и включите расширение:

```bash
gnome-extensions enable vibekeys@pelkons.github.io
```

Для автостопа диктовки нужен `parec` (пакет `pulseaudio-utils`) или `pw-record` (`pipewire-bin`); на
Ubuntu обычно уже есть хотя бы один из них.

## Меню

- **Значок в верхней панели:** показать/скрыть панель, «Масштаб» (30–200 %), «Сочетание для диктовки»
  (Ctrl+Super — по умолчанию в OpenWhispr, Super+Alt), «Показывать панель при входе» (включено по умолчанию).
- **Правый клик по ручке слева:** «Масштаб», «Скрыть панель».
- Ручку можно тянуть, чтобы переместить панель; место запоминается.

Расширение запускается само при входе в систему, пока оно включено. Настройки лежат в
`~/.config/vibekeys/settings.json`.

## Проверка

`test/run-test.sh` запускает GNOME Shell без экрана (так работает CI), открывает окно ввода zenity,
печатает «abc», нажимает Backspace на панели виртуальной мышью, долгим нажатием выбирает «?», жмёт Enter
и ждёт, что zenity выведет «ab?». Тестовый D-Bus-интерфейс расширения включается только переменной
окружения `VIBEKEYS_TEST=1`.

```bash
dbus-run-session -- bash test/run-test.sh /tmp/vibekeys-test
```

## Файлы

- `vibekeys@pelkons.github.io/extension.js` — панель, меню, клавиши, масштаб, долгое нажатие, тестовый интерфейс.
- `vibekeys@pelkons.github.io/silence.js` — прослушивание микрофона для автостопа.
- `vibekeys@pelkons.github.io/stylesheet.css` — цвета.
- `vibekeys@pelkons.github.io/icons/vibekeys-symbolic.svg` — значок для верхней панели.
